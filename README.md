# FluxLedger 本地记账

Vue 3 + Vite 构建的本地记账面板。

## 启动

首次运行 `npm install`，然后运行 `npm run dev`，打开 http://127.0.0.1:4173 。

`npm run build` 生成生产构建，`npm run preview` 预览构建。

## 功能

- 桑基资金流、分类图、月度余额与收支报表。
- 时间、银行卡、分类筛选。
- 交易新增、搜索、删除与撤销、完整历史、CSV 导出。
- 并列的 EN/ZH 与日夜模式切换，自动记忆设置。
- 浏览器 localStorage 保存数据，无后端，无运行时外部资源。

初始数据为演示账目，默认月份 2026 年 9 月。货币沿用参考图的美元。清除网站数据会清除保存记录，可以先导出 CSV。

## 结构

- src/App.vue：Vue 响应式状态和页面组件。
- src/charts.js：SVG 资金流。
- src/locales.js：翻译词典。
- src/seed.js：演示交易。
- style.css：主题与响应式布局。

## 信用额度、编辑与动画

支出、收入和信用额度分别提供查看与新增入口，已有记录可直接编辑。银行卡名称、尾号、卡组织和配色可编辑，固定卡片 ID 保持历史记录关联。

信用额度采用带生效日期的设置记录：图表取所选期间结束日前最新的一条，不累加历史额度，可设为零。额度不计入收入、净收益和收支频次。资金来源仅包括当期收入和生效额度，展示的是资金容量而非现金余额。

可交互控件具有悬停、按压和状态切换动画，弹窗与列表包含入场过渡，并尊重系统减少动态效果设置。

运行 `npm test` 可验证额度覆盖、资金计算、卡片关联与 SVG 边界。
