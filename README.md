# FluxLedger 本地记账

Vue 3 + Vite 构建的本地记账面板。

你可以直接访问 http://leakice.cn 来使用，不过确保你能够科学上网。

如果科学上网后无法访问，请遵循以下方法：

1.将科学上网模式调整全局。

2.将leakice.cn添加入你的科学上网软件的规则栈中，并确保在DRICT CN规则之前。因为.cn在大部分机场的规则栈中为直连。

## 启动

首次运行 `npm install`，然后运行 `npm run dev`，打开 http://127.0.0.1:4173 。

`npm run build` 生成生产构建，`npm run preview` 预览构建。

## 功能

- 桑基资金流、分类图、月度余额与收支报表。
- 时间、账户、分类筛选。
- 交易新增、搜索、删除与撤销、完整历史，以及 JSON 备份/恢复与 CSV 导入。
- 并列的 EN/ZH 与日夜模式切换，自动记忆设置。
- 浏览器 localStorage 保存数据，无后端，无运行时外部资源。

初始数据为演示账目，默认月份 2026 年 9 月。金额统一使用人民币（¥）。清除网站数据会清除保存记录，可以先通过“数据管理”导出完整备份。

## 结构

- src/App.vue：Vue 响应式状态和页面组件。
- src/ledger.js：账本核心逻辑（账户类型、信用额度、信用消费与还款、余额推导、校验）。
- src/charts.js：SVG 容量资金流图与还款流图。
- src/flowInteraction.js：资金图悬停高亮与提示交互。
- src/transactionView.js：交易列表筛选与排序。
- src/dataTransfer.js：JSON 备份/恢复与 CSV 导入。
- src/locales.js：翻译词典。
- src/seed.js：演示交易。
- src/components/：记账、账户与数据管理弹窗。
- style.css 与 src/responsive.css：主题、动画与响应式布局。

## 信用额度、编辑与动画

支出、收入和信用额度分别提供查看与新增入口，已有记录可直接编辑。银行卡名称、尾号、卡组织和配色可编辑，固定卡片 ID 保持历史记录关联。

信用额度采用带生效日期的设置记录：图表取所选期间结束日前最新的一条，不累加历史额度，可设为零。额度不计入收入、净收益和收支频次。资金来源仅包括当期收入和生效额度，展示的是资金容量而非现金余额。

可交互控件具有悬停、按压和状态切换动画，弹窗与列表包含入场过渡，并尊重系统减少动态效果设置。

运行 `npm test` 可验证额度覆盖、资金计算、卡片关联、数据导入导出、记账弹窗、交易列表与 SVG 边界。

## 窄屏适配

- 800px 及以下使用双行导航、并列语言/主题切换和可折叠筛选。
- 640px 及以下将交易表替换为完整信息卡片，保留编辑、删除与撤销入口。
- 窄窗口资金图保持可读尺寸，在图内左右滑动或用键盘滚动，不撑宽整页。
- 手机表单使用单列输入，支持短横屏弹窗滚动和安全区域留白。
- 样式集中在 `src/responsive.css`，兼容中英文、日夜模式和减少动态效果设置。

## 信用消费与还款

- 在支出表单勾选“信用消费”，该笔支出计入消费统计并产生对应账户的待还负债，不扣减现金余额。已有普通支出保持原含义；需要时可以编辑勾选。
- 通过“记还款”选择付款账户和待还消费，或从消费记录直接发起还款。支持多次部分还款，全额还款后显示“已还清”。
- 还款单独记录付款账户、信用账户和消费编号；只减少付款账户现金及对应负债，不再次计入收入或消费支出。
- Sankey 上方保留收入与额度的容量图；下方还款图显示实际的“付款账户 → 信用账户”流线，可展开查看每笔还款和关联消费。分类筛选按关联消费分类匹配，单账户筛选保留另一端账户名称。
- 账户面板按所选期间截止日累计计算“已记录现金余额”和“未还负债”。现金余额从已有收入和现金支出推导，未录入的期初余额不包含在内。
- 编辑、删除、撤销还款会重新计算余额；超额、负数、自账户还款及早于消费的还款被拒绝。有关联还款的消费须先移除还款才可删除。
- 数据仍保存在本机浏览器 localStorage；旧记录无信用消费标记时不自动转换。
